\subsection{Model simulation}\label{model-simulation}

Given the parameters of a model, we can use ODE solvers to predict the
behavior of a model, \(x(t)\).

Given data, can we find which model parameters are the best fit?

\begin{enumerate}
\def\labelenumi{\alph{enumi}.}
\item
  Write code to simulate the following model

  \begin{equation}\protect\phantomsection\label{eq-generalized-logistic}{\frac{dN}{dt} = \lambda N \left( 1 - \left(N/\theta\right)^\alpha\right)}\end{equation}

  where the user (you) specifies the parameter values \(\lambda=1\),
  \(\theta=10^3\), \(\alpha=2\), and the initial condition \(N(0)=200\).
  Plot a time series of \(N_\mathrm{sim}(t)\).
\end{enumerate}

\subsection{Data analysis}\label{data-analysis}

\begin{enumerate}
\def\labelenumi{\alph{enumi}.}
\setcounter{enumi}{1}
\tightlist
\item
  Write code that loads bacterial growth experimental data into two
  arrays: one for the amount of bacteria \(N_\mathrm{exp}(t_i)\) and the
  other for the measurement time points \(t_i\). Plot the time series
  \(N_\mathrm{exp}(t_i)\).
\item
  Plot the solution \(N(t)\) and the experimental data
  \(N_\mathrm{exp}(t)\) on the same axes. Set \(N(0)\) to match the
  experimental data exactly. Manually explore different parameter values
  of \(\lambda,\theta,\alpha\) to see which values best fit the data.
\end{enumerate}

\subsection{Parameter learning}\label{parameter-learning}

\begin{enumerate}
\def\labelenumi{\alph{enumi}.}
\setcounter{enumi}{3}
\item
  Write code that computes the sum of squared error (SSE), which is

  \[\mathrm{SSE} = \sum_i \left( N_\mathrm{sim}(t_i) - N_\mathrm{exp}(t_i)\right)^2\]

  Hint: The Matlab solver \texttt{ode45} can take a time vector as an
  input argument. If the time vector has more than two elements, it will
  return the solution only at those elements. This is useful if you only
  need the solution at certain times \(t_i\).
\item
  Using the code from the previous part, create a \emph{function} that
  takes parameters and returns the SSE. Hint: A function can be defined
  in a separate m-file.
\item
  Use an automated minimization algorithm like Matlab's
  \texttt{fminsearch} to find the parameters that minimize the sum of
  squared error. These parameters are the ``best fit'' or ``maximum
  likelihood'' parameters \(\hat\lambda,\hat\theta,\hat\alpha\). Plot,
  on the same axes, the experimental and best-fit model time series,
  \(N_\mathrm{exp}(t)\) and \(N_\mathrm{sim}(t)\).
\end{enumerate}
